Happy Tails Pet Adoption System

A modern full-stack animal welfare platform connecting loving families with verified rescue shelters.

Java 21 (Native HTTP Server) Apache Maven 3.9.16 MySQL 8.0 PBKDF2 Password Encryption Vanilla HTML5 / Modern CSS / ES6
LAYER OVERVIEW

Three-Tier Architecture

1
🗄️

MySQL Database

Port: 3306 • DB: pet_adoption_system
  • ✓ users: Stores user, partner, and admin accounts
  • ✓ partners: Shelter names, address, verification status
  • ✓ pets: Pet profiles, breed, age, status, images
  • ✓ adoption_requests: Multi-status workflow tracking
  • ✓ Security: PBKDF2 salted hash password storage
2
⚡

Java REST Server

Port: 8080 • com.petadoption
  • ✓ HttpServer: High-throughput native Java server
  • ✓ Thread Pool: 10 worker threads concurrent handling
  • ✓ Services & DAOs: Modular business logic & SQL
  • ✓ Endpoints: /api/login, /api/pets, /api/partner/register
  • ✓ Health API: GET /api/health instant ping
3
🖥️

Web Frontend Portals

Port: 3000 • HTML / CSS / JS
  • ✓ Adopter Portal: Browse pets, apply for adoption
  • ✓ Partner Portal: Minimal login & shelter register
  • ✓ Admin Portal: Review shelters & approve requests
  • ✓ Zero Framework: Fast, pure DOM & Fetch API
  • ✓ Responsive: Optimized for mobile & desktop
EXECUTION GUIDE

Step-by-Step Setup Blueprint

STEP 1

Initialize Database

Ensure MySQL is running on port 3306 and import the database schema:

# In MySQL Workbench or CLI:
mysql -u root -p < database\database.sql

# Check DatabaseConnection.java:
URL: localhost:3306/pet_adoption_system
USERNAME: root | PASSWORD: [your_pass]
STEP 2

Compile & Start Backend

Use the bundled Maven binary to compile and start the Java server:

# 1. Compile:
.\apache-maven-3.9.16\bin\mvn.cmd -f backend\pom.xml clean compile

# 2. Run Server:
.\apache-maven-3.9.16\bin\mvn.cmd -f backend\pom.xml exec:java
STEP 3

Launch Frontend

Serve the frontend static files using Python or open index.html:

# Start local HTTP server:
python -m http.server 3000 --directory frontend

# Open in browser:
http://localhost:3000
