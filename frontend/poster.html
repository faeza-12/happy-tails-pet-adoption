HAPPY TAILS PET ADOPTION SYSTEM

A High-Performance Full-Stack Platform for Animal Rescue Management, Ethical Adoption Workflows, and Multi-Tenant Partner Sanctuaries.

Java 21 SE (Native HttpServer) Apache Maven 3.9.16 MySQL 8.0 Relational Engine PBKDF2 Salted Hashing Zero-Framework Client Architecture

System Architecture Blueprint

3-TIER CLIENT-SERVER
TIER 1 : DATA PERSISTENCE PORT 3306

MySQL 8.0 Database

  • ▶ Schema: pet_adoption_system
  • ▶ users: Multi-role authentication (User, Admin, Partner)
  • ▶ partners: Shelter profiles & verification queue
  • ▶ pets: Profiles, breeds, age, status, images
  • ▶ adoption_requests: End-to-end request lifecycle
TIER 2 : REST API ENGINE PORT 8080

Java 21 REST Server

  • ▶ Engine: Built-in com.sun.net.httpserver
  • ▶ Concurrency: 10 fixed worker thread pool
  • ▶ Design: Modular DAO & Service pattern
  • ▶ CORS: Cross-origin enabled for local clients
  • ▶ Health API: GET /api/health endpoint
TIER 3 : CLIENT INTERFACES PORT 3000

Modular Web Portals

  • ▶ Adopter Portal: Search pets, apply for adoption
  • ▶ Partner Portal: Dedicated minimal login & dashboard
  • ▶ Admin Portal: Shelter moderation & request review
  • ▶ Zero Dependencies: Pure DOM & modern Fetch API
  • ▶ Responsive: Unified mobile & desktop experience

Core Technical Capabilities

Complete System Setup & Launch Commands

EXECUTION GUIDE
STEP 1 : DATABASE INITIALIZATION

Import MySQL Schema

mysql -u root -p < database\database.sql

# In DatabaseConnection.java:
URL: "localhost:3306/pet_adoption_system"
USER: "root" | PASS: "[your_mysql_pwd]"
STEP 2 : BACKEND REST SERVER

Compile & Run with Maven

# 1. Clean & Compile:
.\apache-maven-3.9.16\bin\mvn.cmd -f backend\pom.xml clean compile

# 2. Start Java Server:
.\apache-maven-3.9.16\bin\mvn.cmd -f backend\pom.xml exec:java
STEP 3 : FRONTEND CLIENT HOST

Launch Static Web Server

# Run Python HTTP Server:
python -m http.server 3000 --directory frontend

# Access in Browser:
http://localhost:3000
